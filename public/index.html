ระดับที่ 2 (โพสต์ตรงขึ้นเพจ FB) 📘 โพสต์ขึ้นเพจ Facebook อัตโนมัติ (Graph API)

ใส่ Facebook Page ID และ Page Access Token ด้านล่าง เมื่อกดปุ่ม "📤 สั่งโพสต์ลงเพจ" โปรแกรมจะยิงโพสต์ขึ้นหน้าเพจ Facebook ของคุณทันทีโดยไม่ต้องเปิดแอป!

ระดับที่ 3 (กระจายลง TikTok + IG + FB) ⚡ เชื่อม Automation Webhook (Make / n8n / Zapier)

สำหรับ TikTok และ IG สามารถนำลิงก์ Webhook จาก Make.com หรือ n8n มาวาง เพื่อให้พอกดปุ่มสั่งโพสต์ ระบบจะส่งทั้งแคปชัน สคริปต์ และสื่อไปลงครบทุกเพจพร้อมกัน!

🔗 1. เปิดหน้าขอ Token ฟรี
💡 แนะนำ! การใช้ Make.com จะช่วยให้โพสต์ลงเพจ Facebook จริงได้ทันทีโดยไม่ต้องขอสิทธิ์แอป Meta (#200)

📖 วิธีเอา Token มาเชื่อมเพจ Facebook ให้โพสต์เองอัตโนมัติ (ทำครั้งเดียวใช้ได้ตลอด)

  1. เข้าเว็บ Facebook Graph API Explorer (ล็อกอินเฟซบุ๊กที่เป็นแอดมินเพจ)
  2. ที่ช่องขวาบน User or Page ให้เลือกชื่อเพจของคุณ และเพิ่มสิทธิ์ pages_manage_posts และ pages_read_engagement
  3. กดปุ่ม Generate Access Token แล้วคัดลอกรหัสยาวๆ (`EAA...`) มาวางในช่อง Facebook Page Access Token ด้านบน
  4. กดปุ่ม "🔍 ดึง Page ID จาก Token อัตโนมัติ" ระบบจะดึงเลข Page ID และชื่อเพจมาใส่ให้เองทันที แล้วกด บันทึก ได้เลย!
